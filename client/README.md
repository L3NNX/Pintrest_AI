# Pintrest_AI Client

Modern, responsive Pinterest Single Page Application built with **React 19**, **Vite**, **TypeScript**, and **Tailwind CSS v4**.

## Architecture & Features
- **Pinterest Masonry Grid**: Multi-column fluid layout with responsive columns and skeleton loaders.
- **Pin Detail Modals**: Modal overlay for pin preview preserving feed scroll position.
- **Direct-to-Cloudflare R2 Uploads**: Drag-and-drop file uploader uploading directly to R2 bucket via presigned URLs.
- **Optimistic Interactions**: Instant like toggles and saved pin states.
- **TypeScript & Type Safety**: Strongly-typed data models and API services.
